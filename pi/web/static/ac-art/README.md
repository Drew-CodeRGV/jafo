Licensed aircraft illustrations go here (never commit art you don't hold a licence for).

manifest.json maps a key to a file in this folder:
  "UAL_A319": "united-a319.webp"   airline ICAO prefix + ICAO type (wins)
  "A319": "a319-generic.webp"      type only
Anything not listed falls back to the generated drawing in static/acprofile.js.
