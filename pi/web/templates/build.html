Build a JAFO station

From a box of parts to your own live radio station in about an hour. Most of that time is the installer running on its own. You don't need to know Linux; you'll copy and paste a few commands.

1. Parts

The full list, with links, is on the About page. In short:

  • Raspberry Pi 5, with the official 27 W USB-C power supply and an active cooler.
  • A microSD card of 32 GB or more. Look for "A2" on the label.
  • Airspy R2, which listens to police, fire and EMS.
  • RTL-SDR (optional), which listens to aircraft.
  • An antenna. Use what you have.
  • If one antenna feeds both radios: a splitter, two SMA jumpers and a PL-259 to SMA cable.
  • A computer (Windows, Mac or Linux) with a microSD slot or a USB card reader, used once to set up the card.
  • Internet for the Pi. Wired Ethernet is best; Wi-Fi works.

2. How it connects

Two antennas instead of one? Skip the splitter and jumpers: each antenna goes straight to its own radio, using a PL-259 to SMA cable if needed.

  1. Mount the cooler on the Pi

    Peel the backing from the thermal pads, press the cooler on, and plug its little fan cable into the FAN header next to the USB ports. The Pi gets hot running radios all day, so don't skip this.

  2. Build the antenna side

    Screw the PL-259 to SMA cable onto the antenna's coax, and its SMA end onto the splitter's IN port. Connect an SMA jumper from each OUT port to each radio's antenna jack. Finger-tight is enough. SMA threads are small, so never force them.

  3. Plug the radios into the Pi

    Plug both radios straight into the Pi's USB ports; either colour works. If they don't fit side by side, use a short USB extension cable. That also moves the RTL-SDR's heat and noise away from the Pi. Avoid unpowered USB hubs.

  4. Leave power for last

    Don't plug in the power supply yet. You'll do that in step 5, once the card is ready.

3. Where to put the antenna

The antenna matters more than any other part, and its position matters more than its price.

  • Get it high. At 800 MHz and 1090 MHz, signals travel roughly line-of-sight. Every floor of height helps, and a roof or mast is best.
  • Get it outside, or near a window. Walls, low-E window coatings, foil-backed insulation and metal roofs all block signal. Indoors, use the highest window that faces the nearest radio towers.
  • Stand it up straight. Public-safety radio and aircraft both transmit vertically polarised signals, so mount the antenna vertically, not lying flat.
  • Point it toward the towers. You can see your system's tower sites on RadioReference. A clear view toward even one of them beats a perfect antenna in the wrong spot.
  • Keep it away from noise. Keep it at least a few feet from the Pi, power bricks, LED bulbs, TVs and routers, which all leak radio noise.
  • Keep the cable short. Long, thin coax loses a lot of signal at these frequencies. For runs over about 15 ft, use low-loss cable such as LMR-400.
  • Outdoors, protect against lightning. Ground the mast and add a coax lightning arrester where the cable enters the building. Follow your local electrical code, or ask an installer.
Start simple: put the antenna in a window, finish the setup, and look at how many calls come in. Move it higher later and you'll see the difference straight away.

4. Prepare the microSD card

You'll use your computer to put the Pi's operating system on the card. This takes about 10 minutes.

  1. Install Raspberry Pi Imager

    Download it free from raspberrypi.com/software. It's available for Windows, macOS and Ubuntu. Install and open it.

  2. Put the card in your computer

    Many laptops have an SD slot. Slide the microSD into the full-size adapter that came with it, label side up, and push it in until it clicks. No slot? Use a USB card reader. Windows may offer to "format" the card; click Cancel.

  3. Choose the device, the system and the card

    In Imager:

    • Device: Raspberry Pi 5.
    • Operating system: Raspberry Pi OS (other) → Raspberry Pi OS Lite (64-bit). "Lite" has no desktop, which is what we want. JAFO is tested on the Bookworm release; if Lite is a newer release, choose the Legacy 64-bit Lite option, which is Bookworm.
    • Storage: your microSD card. Check the size so you don't pick a different drive.

  4. Customise the settings (important)

    When Imager asks whether to apply OS customisation, choose Edit settings (newer versions show these as steps). Set:

    • Hostname: jafo
    • Username: pi (it must be exactly pi) and a password you'll remember.
    • Wi-Fi: your network name and password, and your country. Skip this if you'll use an Ethernet cable.
    • Time zone and keyboard layout.
    • Services: turn on Enable SSH with password authentication.

    Save, then confirm. Writing erases the card. When Imager says it's done, eject the card.

5. First boot

  1. Insert the card into the Pi

    The microSD slot is on the underside of the Pi, at the end opposite the USB ports. Hold the card with its metal contacts facing the board and slide it in until it stops.

  2. Connect the network

    Plug in an Ethernet cable from your router, if you're using one.

  3. Plug in the power

    Use the 27 W supply. The first boot takes 2 to 3 minutes while it sets itself up, so give it time before the next step.

6. Log in to the Pi

You'll control the Pi from your computer, using a terminal window and a program called SSH.

  • Windows: open the Start menu, type Terminal (or PowerShell), and open it.
  • Mac: press ⌘ Space, type Terminal, and open it.
  • Linux: open your terminal.

Type this and press Enter:

ssh pi@jafo.local

The first time, it asks if you trust this computer; type yes. Then enter the password you chose in Imager. Nothing shows as you type it; that's normal. You're in when the prompt reads pi@jafo:~ $.

If you get "could not resolve hostname", open your router's app or admin page, find the device named jafo and note its address (like 192.168.1.57). Then run ssh pi@192.168.1.57 with that address.

7. Install JAFO (one command)

Copy this whole line into the terminal and press Enter:

curl -fsSL https://raw.githubusercontent.com/Drew-CodeRGV/jafo/main/bootstrap.sh | bash

It downloads JAFO, installs the radio software, finds your radios, and sets up every service. Expect 25 to 35 minutes, mostly while it builds the radio decoder. It ends with a summary listing each service and its status.

  • Keep the terminal open and the Pi powered while it runs.
  • If the connection drops, log back in and run the same line again. It's safe to repeat and picks up where it left off.
  • Plug the radios in before you run it, so it can find them. If you add a radio later, run bash ~/jafo/pi/install-pi.sh again.

8. Add your own keys

JAFO uses a few outside services to turn audio into text and text into stories. Each station uses its owner's own accounts. Your keys are billed to you, stay on your Pi, and are never shared with JAFO or anyone else.

GroqTurns radio audio into text (Whisper).Yes, for transcriptsconsole.groq.com → API Keys → Create

Once you have them, run the key setup on the Pi:

bash ~/jafo/scripts/setup-keys.sh

It asks for each key in turn. Paste with right-click, or Ctrl+Shift+V in most terminals; the key stays hidden as you paste. Press Enter to skip one you don't have yet. It saves them in a file only your Pi user can read, then restarts what's needed. Run it again whenever you want to add or change a key.

Keep keys private. Don't post them, email them or paste them into chats. In each service's console, set a monthly spending limit so a busy night can't surprise you. If a key ever leaks, delete it there and make a new one.

9. Find your radio system

Tell JAFO where it is. It works out your location, finds the nearest trunked public-safety system and the towers it can hear, and loads the talkgroup names:

python3 ~/jafo/pi/tools/relocate.py

It shows a plan: the system, the nearest site, the control channels and how many talkgroups it found. Type y to apply it. Within a minute or two, calls start arriving.

Then open http://jafo.local in a browser on any phone or computer on the same network to see your station.

JAFO listens to unencrypted P25 trunked systems, the most common kind in the U.S. If your area's police are encrypted, you'll still hear fire, EMS and the other services that aren't. Read Is this legal? before you share anything publicly.

10. Share it on jafo.live (optional)

Your station works on its own at http://jafo.local. To add it to the public jafo.live map, so your town gets a Briefing, map and alerts, ask for a node token with the station request form. We'll email it to you. Then run bash ~/jafo/scripts/setup-keys.sh again and paste the token when it asks.

A shared station sends its recordings and transcripts to jafo.live, which does the heavy processing and keeps the archive. The Pi itself keeps only the last few hours.
